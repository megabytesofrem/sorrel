# Sorrel
An experimental programming language. 🌿

## Syntax
```
def main() {
  let x: i32 = 5
  let y: i32 = 10
  let z: i32 = x + y
  print(z)
}
```

## Ideas
- Programs should be incredibly structured and the language should enforce a topological form of memory safety using category theory. The entire program is modelled as a presheaf over a category of
regions, each with their own types.

- The type system should support expressing higher-kinded types
